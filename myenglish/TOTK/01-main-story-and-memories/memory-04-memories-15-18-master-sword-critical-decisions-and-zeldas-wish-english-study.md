## KHUNG RÁP NGHĨA

| Mục đích | Khung English | Ví dụ đúng phạm vi |
|---|---|---|
| Treat an object as evidence | `The damaged ___ proves ___, but it does not yet show ___.` | `The damaged sword proves Link is alive, but it does not yet show how Zelda will restore it.` |
| Explain a restoration condition | `The blade can recover if it ___.` | `The blade can recover if it absorbs sacred power for a very long time.` |
| Separate decision and action | `Zelda decides to ___ in Memory 16; she actually ___ in Memory 17.` | `Zelda decides to use draconification in Memory 16; she actually swallows the stone in Memory 17.` |
| State informed cost | `She knows ___, yet chooses ___ because ___.` | `She knows she will lose herself, yet chooses transformation because it can carry and restore the sword.` |
| Track a handoff | `Before ___, Zelda entrusts ___ to ___.` | `Before transforming, Zelda entrusts the Purah Pad to Mineru.` |
| Hold the final wish | `The wish directs ___ toward ___; it does not narrate ___.` | `The wish directs the Master Sword toward Link; it does not narrate the final battle.` |
