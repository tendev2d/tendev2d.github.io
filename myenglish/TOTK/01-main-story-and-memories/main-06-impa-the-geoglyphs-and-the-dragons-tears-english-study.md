## Đáp án

### Đáp án Test 0

Bốn cụm chỉ là retrieval. Tower launch có thể là traversal option; falling-rock elevator, cloud dive và Depths lighting không phải required states của geoglyph memory arc.

### Đáp án Test A

Damaged balloon (visual state) → Ultrahand repair (action) → aerial outline (perspective result) → tear-shaped target (visual clue) → pool examination (action) → `Where Am I?` (exact memory/UI playback).

### Đáp án Test B

Floor map indexes places; murals provide a narrative/chronology reference; player route determines actual collection/playback. Ví dụ: fast travel to an eastern geoglyph before a western one changes route order but not the archive's suggested sequence.

### Đáp án Test C

One first mapped Tear plus ten remaining mapped Tears makes eleven. Completion of those eleven triggers an extra final Tear at Rist Peninsula; it is not another original geoglyph marker.

### Đáp án Test D

Each window confirms one later pool/memory/progress state in BeardBear's run. The walkthrough chooses travel order. It cannot prove another player watched the same memory at the same quest count.

### Đáp án Test E

Valid answer: “The final memory reveals Zelda's draconification. It explains the Light Dragon's role. It does not complete Link's present mission. Rescuing Hyrule still requires later action.”

### Đáp án Test F

Đạt khi đủ six anchors, correctly says order is open and ends with `The Dragon's Tears` complete while the present crisis remains unresolved.

### Đáp án tự kiểm tra từng beat

- **Beat 1 —** aerial view reveals the whole outline; repair→rise→locate; exact assembly/path vary.
- **Beat 2 —** `Where Am I?`; Impa quest completes and Tears quest begins; Zelda is in an unfamiliar past while full path is unknown.
- **Beat 3 —** Forgotten Temple as archive destination; traversal lacks locked speech clock; next evidence is map/mural rather than Tear playback.
- **Beat 4 —** one first Tear leaves ten; floor map indexes locations while murals reference sequence; “The murals suggest chronology, but collection order remains open.”
- **Beat 5 —** pool trigger plus log change; walkthrough route is not universal; travel gaps are omitted because they vary.
- **Beat 6 —** current Adventure Log count; near-complete lacks eleven condition; archive answers chronology while navigation answers route.
- **Beat 7 —** extra Tear follows eleven; Rist Peninsula fixed while travel method varies; Light Dragon event and Silent Princess/coastal spiral identify finale.
- **Beat 8 —** draconification to restore/carry Master Sword; earlier Light Dragon/Sword clues gain context; memory quest closes while present crisis continues.
